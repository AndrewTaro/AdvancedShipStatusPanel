# Advanced Ship Status Panel
This mod enables the customization of the ship status panel at the bottom left corner.
![image](https://github.com/user-attachments/assets/b7e1efcb-3d21-412d-a120-a0db29521c9d)

# Customizable Features
- Drag&Drop
- Size of Elements
etc.

# Install
1. Download a zip.
2. Unzip the archive, and you should get `gui`, `PnFMods`, `ModSchemas` folders, and `PnFModsLoader.py`.
3. Move them to `(wows)/bin/(latest_number)/res_mods/`. So the path will look like `res_mods/PnFModsLoader.py`, etc.
4. Done!

# Requirements
You must install the following in order to use the mod.
- [TTaro Mod Config](../../../TTaroModUtils)

# Note on `ModSchemas/`

> [!WARNING]
> These files are generated by my own config tool. Do not edit them, and do not copy one
> into another mod: the `id` inside names the player's settings file, so a reused `id` makes
> the framework refuse **both** mods' settings. Trouble from an edited or copied schema is
> not a bug in my mods.
